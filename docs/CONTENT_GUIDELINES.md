# Content Guidelines

## Product content
All product claims must come from approved source material. The rule for what to do when a fact isn't available (never invent, use `TBD`) lives in `guidelines/DO_NOT_CHANGE.md` — this file does not restate it.

## Copy principles
- Be concise.
- Use consistent terminology.
- Prefer specific factual language over vague marketing claims.
- Do not claim performance characteristics without evidence.
- Keep technical labels understandable to the intended audience.

## Technical terms
Use the exact approved product terminology. If multiple terms refer to the same construction element, choose one canonical term and document it in `docs/PRODUCT_CATALOG.md`.

## UI labels
Labels should describe the action or information directly.

Avoid ambiguous labels such as:
- More
- Stuff
- Explore

Prefer labels that identify the actual result or function.
